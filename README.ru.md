# Birchpad

<img src="packaging/icons/birchpad.svg" alt="" width="96" align="right">

[English](README.md) · Русский

Быстрый расширяемый кроссплатформенный текстовый редактор в духе Notepad++, написанный на Rust.

> **Состояние: альфа (0.6).** Редактор наподобие Notepad++: вкладки и разделённые виды,
> кодировки, подсветка синтаксиса для 50 языков со свёрткой, несколько курсоров и правка
> столбцов, закладки, сессии, сохраняющие несохранённую работу, поиск в файлах, макросы, темы,
> интерфейс на английском, немецком и русском, плагины в виде компонентов WebAssembly и скрипты на
> Rhai; сравнение, инструменты для JSON и XML, шестнадцатеричный вид, предпросмотр Markdown и
> PlantUML и проверка орфографии встроены. Дальше — полное соответствие Notepad++. Возможны
> шероховатости. См. [план развития](docs/ROADMAP.ru.md) и [список изменений](CHANGELOG.md).

## Цели

- **Сначала — всё, что умеет Notepad++**: вкладки и разделённые виды, несколько курсоров и
  правка столбцов, подсветка синтаксиса и свёртка, мощные поиск с заменой и поиск в файлах,
  макросы, сессии, никогда не теряющие несохранённую работу, пользовательские языки и темы.
- **Затем — дальше**: LSP, палитра команд, интеграция с Git, встроенный терминал, режим
  огромных файлов, плагины на любом языке через WebAssembly.
- **Нативно и быстро**: интерфейс отрисовывается на GPU, без браузерного движка, мгновенный
  запуск.
- **Кроссплатформенность**: Windows, Linux и macOS с первого дня.
- **Готовность к предприятию**: MSI для установки на компьютер, шаблоны групповых политик и
  Intune, каналы обновлений под контролем администраторов и гарантированный режим без сети.

## Почему «Birchpad»?

Пока в средневековом Новгороде бумага не стала обычной, повседневные записки, письма и
ученические упражнения писали на полосках бересты. Эти берестяные грамоты были блокнотами
своего времени, и Birchpad («берестяной блокнот») назван в их честь.

## Установка

Загрузки — на [странице выпусков](https://github.com/SecurityTrip/Birchpad/releases):

| Файл | Для чего |
|---|---|
| `birchpad-<версия>-windows-x64-setup.exe`, `…-windows-arm64-setup.exe` | Windows, установка для текущего пользователя без прав администратора; обновляется сам |
| `birchpad-<версия>-windows-x64.msi` | Windows, установка на компьютер администраторами, которые его и обновляют |
| `birchpad-<версия>-windows-x64.zip`, `…-windows-arm64.zip` | Windows, переносная версия: распакуйте и запускайте |
| `birchpad-<версия>-macos.zip` | macOS 10.15.7 и новее, Apple silicon и Intel (`Birchpad.app`) |
| `birchpad-<версия>-linux-x64.zip` | Linux x64, переносная версия |

Чтобы Birchpad появился в меню приложений Linux, поместите `birchpad` в `PATH` и скопируйте
`io.github.securitytrip.birchpad.desktop` в `~/.local/share/applications/`, а
`io.github.securitytrip.birchpad.png` — в `~/.local/share/icons/hicolor/512x512/apps/`.

Выпуски для Windows пока не подписаны (см. [политику подписи кода](#политика-подписи-кода)),
поэтому Windows SmartScreen спрашивает перед первым запуском («Подробнее», «Выполнить в любом
случае»). На macOS, пока приложение не нотаризовано, Birchpad.app нужно один раз открыть через
Control-щелчок > Открыть. К каждому выпуску прилагаются контрольные суммы SHA-256 и сведения о
происхождении сборки GitHub (`gh attestation verify <файл> --repo SecurityTrip/Birchpad`).

В Windows установщик и MSI добавляют «Edit with Birchpad» в контекстное меню файлов Проводника
(в MSI компонент `ExplorerMenu` можно не ставить: `ADDLOCAL=Main`); Preferences > Files добавляет
этот пункт для переносной копии или убирает его. При первом запуске Birchpad предлагает
открывать текстовые файлы (позже это делает Settings > Make Birchpad the Default Editor): в
Windows затем выберите его в «Приложениях по умолчанию» — программы не могут сделать это сами;
в macOS — Свойства в Finder > Открывать в программе > Изменить всё.

Чтобы удалить программу, используйте «Установленные приложения» в параметрах Windows для
установщика и MSI или удалите папку переносной копии.

Ночные сборки ветки следующей версии (`v0.6.1` или `v0.7.0` после 0.6.0) публикуются как
предварительные выпуски; задайте `updates.channel = "nightly"`, чтобы получать их как обновления.

## Политика подписи кода

Выпуски для Windows пока не подписаны. Процесс выпуска готов подписывать исполняемый файл
Windows, установщики для пользователя и MSI каждого выпуска (не ночные сборки) через SignPath и
остаётся выключенным, пока у Birchpad нет сертификата подписи кода; см.
[ADR 0021](docs/adr/0021-authenticode-signing-with-signpath.md). До тех пор контрольные суммы
SHA-256 каждого выпуска и сведения о происхождении сборки GitHub показывают, что загрузка —
это то, что процесс выпуска собрал из исходного кода этого репозитория на машинах GitHub.

Политика конфиденциальности: Birchpad не собирает персональных данных и выходит в сеть только
для проверки и загрузки обновлений, что можно отключить, и — когда вы просите — для установки
PlantUML, плагинов и словарей; см. [PRIVACY.ru.md](PRIVACY.ru.md).

## Сборка

Birchpad нужен набор инструментов Rust, закреплённый в [`rust-toolchain.toml`](rust-toolchain.toml)
(rustup ставит его сам).

```bash
cargo run -p birchpad
```

```bash
cargo nextest run --workspace
```

или `cargo test --workspace`, медленнее; проверки, которые выполняет CI, описаны в
[CONTRIBUTING.ru.md](CONTRIBUTING.ru.md#разработка).

## Командная строка

Birchpad принимает параметры Notepad++ (их перечисляет Help > Command Line Arguments...):

```text
birchpad [-n<line>] [-c<column>] [-p<position>] [-l<language>] [-udl="name"] [-ro]
         [-monitor] [-r] [-multiInst] [-nosession] [-openSession] [-openFoldersAsWorkspace]
         [-notabbar] [-alwaysOnTop] [-systemtray] [-x<left>] [-y<top>] [-titleAdd="text"]
         [-settingsDir="folder"] [-loadingTime] [-quickPrint] [-qt="text"] [-qf="file"]
         [-qSpeed<1-3>] [-nopluginsupport] [-pluginMessage="text"] [FILE]...
```

Второй запуск открывает свои файлы вкладками в уже открытом окне и завершается; `-multiInst`
вместо этого запускает отдельный экземпляр — как и любой запуск или запуск с `-openSession`,
если так задано в Preferences > Multi-Instance (`instances.mode = "multi"` или `"session"`).
`-l` принимает названия языков Notepad++ (`-lcpp`, `-lpython`, `-lnormal`), `-openSession`
открывает файлы как сессии. Имена файлов с `*` и `?` открывают все подходящие файлы, а с `-r`
— и во вложенных папках. `-quickPrint` печатает файлы на принтере по умолчанию и завершает
работу; `-qt` и `-qf` набирают текст в новом документе. Параметры окна (`-notabbar`,
`-alwaysOnTop`, `-x`, `-y`, `-titleAdd`, `-settingsDir`, ...) действуют при запуске Birchpad.
`-systemtray` запускает свёрнутым, так как значка в области уведомлений пока нет;
`-pluginMessage` передаёт свой текст плагинам, которые его просят; `-qn` (пасхалки самого
Notepad++) принимается и ничего не делает.

## Переносной режим и сеть

Положите рядом с исполняемым файлом файл `birchpad-portable.txt` (в ZIP для Windows и Linux он
уже есть), и Birchpad будет хранить настройки и данные в папке `data` рядом с собой. Политики
администратора для компьютера при этом действуют.

Сам по себе Birchpad выходит в сеть только для проверки обновлений: раз в день и когда вы
выбираете Help > Check for Updates. Он читает манифест, подписанный ключом проекта, и отвергает
любой другой; установленные копии (установщик Windows) обновляются при перезапуске Birchpad,
остальные показывают, где скачать новую версию. С `updates.mode = "off"` (настройка или
политика администратора) Birchpad не делает обновлений; `"notify"` сообщает о новых версиях, не
скачивая их. PlantUML, плагины из онлайн-списка и словари скачиваются, только когда вы просите,
и не скачиваются при `network.online-features = false`. См.
[ADR 0020](docs/adr/0020-signed-updates-and-nightly-builds.md) и
[политику конфиденциальности](PRIVACY.ru.md).

## Устройство репозитория

| Путь | Содержимое |
|---|---|
| `crates/core` | Модель текста: буфер-верёвка, выделения, наборы изменений, транзакции, история отмены, поиск. Без интерфейса. |
| `crates/config` | Многоуровневые настройки: умолчания, умолчания компьютера, настройки пользователя, политики администратора; сессии. |
| `crates/i18n` | Языки интерфейса: локали YAML, тексты по ключам, формы множественного числа, текущий язык. Без интерфейса. |
| `crates/commands` | Каталог команд, раскладки клавиш, модель меню, макросы и команды запуска — как данные. Без интерфейса. |
| `crates/io` | Определение и преобразование кодировок, чтение и надёжное сохранение файлов, поиск по ним (поиск в файлах). Без интерфейса. |
| `crates/view` | Раскладка вида документа по ячейкам: табуляция, перенос строк, видимые строки, текст справа налево. Без интерфейса. |
| `crates/syntax` | Языки и синтаксические деревья: определение, разбор tree-sitter, подсветка, свёртка. Без интерфейса. |
| `crates/cli` | Командная строка, совместимая с Notepad++, и передача файлов единственному экземпляру. Без интерфейса. |
| `crates/tools` | Встроенные инструменты: форматирование JSON и XML, XPath и схемы, шестнадцатеричные дампы, сравнение текстов, орфография, форматы дат, экспорт в HTML. Без интерфейса. |
| `crates/plugin` | Плагины-компоненты WebAssembly (`wit/birchpad.wit`), скрипты Rhai, управление плагинами. Без интерфейса. |
| `crates/update` | Обновления: подписанный манифест, каналы, версии, установка (Velopack в Windows); онлайн-каталог. Без интерфейса. |
| `crates/release-tool` | `birchpad-release`: ключи подписи и манифест обновлений для процессов выпуска. |
| `crates/ui` | Общее для частей окна: реестр команд, настройки и состояние приложения, кнопки диалогов, сообщения пользователю. |
| `crates/editor` | Редактор: буфер, вид редактора, отрисовываемый и редактируемый в GPUI, текущая тема. |
| `crates/menu-bar` | Строка меню, рисуемая в окне в Windows и Linux, с клавиатурным доступом как в Windows. |
| `crates/app` | Настольное приложение: рабочая область, панели документов, боковые панели, диалоги и меню. Устройство описано в ADR 0041. |
| `packaging/` | Упаковка выпусков: MSI для компьютера, пакет приложения macOS, метка переносного режима, подпись обновлений, онлайн-каталог. |
| `docs/` | План развития, записи архитектурных решений и [плагины и скрипты](docs/plugins.ru.md). |

## Отношение к Notepad++

Birchpad — независимый проект, не связанный с Notepad++ или его авторами и не одобренный ими.
Это реализация «с чистого листа»: в нём нет кода Notepad++, Scintilla или плагинов Notepad++,
и он написан по руководству пользователя Notepad++, по его поведению, каким его видит
пользователь, и по его форматам файлов, но никогда по его исходному коду
([правила](CONTRIBUTING.ru.md#чистая-комната)). Birchpad читает темы, сессии, пользовательские
языки и другие файлы Notepad++ из копии самого пользователя, чтобы они переносились, но не
поставляет их. Notepad++ упоминается только для описания этой совместимости.
