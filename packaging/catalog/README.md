# The online catalog

`catalog.json` is the list Plugins Admin and Plugins > Spell Checker > Download Languages...
read (ADR 0051), from this branch of the repository on GitHub. Each file is pinned by its size
and SHA-256; a plugin is a ZIP with its `plugin.toml` at the top. Add a plugin or a dictionary
with a pull request that says where it comes from and under which license.
