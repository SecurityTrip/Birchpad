# Кодекс поведения

[English](CODE_OF_CONDUCT.md) · Русский

Birchpad принимает [Contributor Covenant, версия 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Коротко: уважайте других, исходите из добрых намерений и думайте о том, что лучше для
сообщества. Травля и личные нападки недопустимы ни в одном из пространств проекта.
