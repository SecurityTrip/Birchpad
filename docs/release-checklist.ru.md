# Список проверок выпуска

[English](release-checklist.md) · Русский

Тесты в CI покрывают то, что может проверить программа (CONTRIBUTING.ru.md, «Тесты»). Этот
список — то, что они не могут: настоящие методы ввода, экранные дикторы, дисплеи, установщики
и обновления на настоящих системах. Перед публикацией черновика выпуска (ADR 0009)
сопровождающий проходит его с артефактами самого черновика, а не с локальной сборкой, и
отмечает в выпуске, что не проверено или не работает.

Отмечайте каждый пункт хотя бы на одной машине каждой платформы: Windows 11 x64, macOS на Apple
Silicon, Linux (Ubuntu или Debian, под X11 и под Wayland). Windows на ARM, Mac с Intel и другие
рабочие среды приветствуются, но не обязательны.

## Перед тегом

- [ ] CI в `main` зелёный, включая необязательные задания (Windows на ARM, сквозные тесты в
      Linux и macOS, фаззинг); причина красного понята и записана
- [ ] `CHANGELOG.md`: раздел `[Unreleased]` становится разделом версии с датой; версия рабочей
      области в `Cargo.toml` совпадает с тегом
- [ ] `cargo run -p birchpad-release-tool -- crate-versions` проходит: crate'ы, изменившиеся с
      прошлого выпуска, подняли версии, остальные сохранили (процесс выпуска проверяет это
      снова)
- [ ] `docs/ROADMAP.md` и `docs/ROADMAP.ru.md` отмечают, что даёт выпуск

## Установщики и первый запуск

- [ ] MSI для Windows (стабильные версии): устанавливается, ярлык в меню «Пуск» запускает
      Birchpad с его значком, Проводник показывает его имя и версию в свойствах исполняемого
      файла; установка поверх прошлой версии сохраняет настройки и сессию; удаление оставляет
      данные пользователя
- [ ] Установщик Windows для пользователя: ставится без прав администратора, запускается и
      появляется в Параметры > Приложения
- [ ] Переносные ZIP: распакованный куда угодно, Birchpad хранит всё в своей папке `data`
      (Help > About говорит portable) и работает рядом с установленной копией
- [ ] macOS: приложение открывается (подпись ad-hoc: в первый раз — Открыть из контекстного
      меню), его значок есть в Dock, а выход из Dock сохраняет сессию
- [ ] Linux: исполняемый файл из ZIP запускается под X11 и под Wayland; с установленным
      desktop-файлом в средстве запуска виден значок
- [ ] Файл, открытый из Проводника, Finder или файлового менеджера, пока Birchpad работает,
      открывается в работающем окне

## Обновления

- [ ] Help > Check for Updates считает прошлый выпуск актуальным и предлагает новый, как только
      он опубликован (каналы stable и nightly)
- [ ] После публикации выпуск есть в подписанном манифесте обновлений (`update-manifest.yml`),
      а установленная прошлая версия с `updates.mode = "auto"` обновляется сама и запускается
      снова со своей сессией
- [ ] С `updates.mode = "off"` ничего не уходит в сеть (Help > Check for Updates недоступен)

## Методы ввода и клавиатуры

- [ ] Windows: японский IME Microsoft и китайский пиньинь; macOS: японский и китайский ввод;
      Linux: IBus и Fcitx 5. Набираемый текст виден у курсора с подчёркиванием, окно вариантов
      открывается рядом, Enter подтверждает, Escape отменяет, а Undo убирает подтверждённый
      текст одним шагом
- [ ] Мёртвые клавиши (US International: `'`, затем `e` даёт `é`) и символы с AltGr (немецкая,
      польская раскладки) набирают свои символы, а не выполняют сочетания клавиш
- [ ] С включённой русской раскладкой Ctrl+C, Ctrl+V, Ctrl+Z и Ctrl+F работают
- [ ] Строка меню с клавиатуры: Alt или F10, Alt+буква, стрелки в подменю

## Экранные дикторы

- [ ] Экранный диктор Windows и NVDA, VoiceOver в macOS: что они читают из заголовка окна, меню,
      вкладок, текста и диалогов, отмечается в выпуске; ухудшение по сравнению с прошлым
      выпуском его блокирует

## Дисплеи

- [ ] Windows при масштабе 100 %, 150 % и 200 % и окно, перенесённое между мониторами с разным
      масштабом: текст, поля, вкладки и панели остаются чёткими и соразмерными
- [ ] macOS на дисплее Retina и на внешнем без Retina; Linux с дробным масштабом под Wayland
- [ ] Шрифты: текст CJK, эмодзи и комбинируемые знаки отображаются; курсор мигает, а выделение
      видно в обоих видах

## Остальная рабочая среда

- [ ] Файлы и папка, перетащенные из файлового менеджера, открываются вкладками и как Folder as
      Workspace
- [ ] Копирование и вставка в другие программы и из них, простым текстом с концами строк
      Windows и Unix; Clipboard History показывает то, что скопировали другие программы
- [ ] Файл, изменённый другой программой, перечитывается или вызывает вопрос, когда окно
      возвращается
- [ ] Файл в 100 МБ открывается, прокручивается и ищется без зависания окна
- [ ] Windows и macOS: с Preferences > MISC > Minimize to system tray свёрнутое окно уходит с
      панели задач (из Dock) в значок в области уведомлений (в строке меню), а щелчок по значку
      возвращает его; `-systemtray` запускает сразу там
