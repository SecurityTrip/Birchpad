# План развития Birchpad

[English](ROADMAP.md) · Русский

Сначала Birchpad достигает всех возможностей Notepad++ (этапы 1–6), затем идёт дальше
(этап 7); завершение этапа 7 выпускает Birchpad 1.0.0. По пути каждый выпуск начиная с 0.2.0
закрывает группу шагов, названную в заголовках этого плана (Release 0.3.0, ...). Этапы
упорядочены по зависимостям, а не по календарю. Архитектурные решения — в [`adr/`](adr).

Этот план ведётся на английском и на русском ([ROADMAP.md](ROADMAP.md)); изменение одного
меняет и другой. Названия меню и настроек оставлены как в программе.

## Этап 0: основа

- [x] Рабочая область, лицензии, правила участия и безопасности
- [x] CI: fmt, clippy, тесты на Windows x64/ARM64, Linux (Ubuntu, Debian 12 и 13), macOS;
      `cargo-deny`
- [x] Модель текста (`birchpad-core`): верёвка, наборы изменений, выделения с несколькими
      курсорами, транзакции, линейная история отмены с отметкой сохранения; модульные тесты и
      тесты свойств
- [x] Многоуровневые настройки с политиками администратора (`birchpad-config`), политики
      реестра Windows
- [x] Пробный GPUI: виртуализированная отрисовка, набор текста, основа для IME, многоязычный
      текст (см. [ADR 0002](adr/0002-gpui-ui-framework.md))
- [x] Заготовка MSI с неизменным `UpgradeCode`

## Этап 1: минимальный блокнот

- [x] Реестр команд: у каждого действия строковый идентификатор и сериализуемые аргументы;
      назначения клавиш и меню — это данные ([ADR 0006](adr/0006-commands-and-keymap.md))
- [x] Вкладки: создать, открыть (несколько файлов), сохранить, сохранить как, сохранить все,
      закрыть, закрыть все, закрыть остальные; метка изменений; Save / Don't Save / Cancel при
      закрытии и выходе; перетаскивание файлов; недавние файлы (настраиваемое число); файлы
      только для чтения и `-ro`
- [x] Кодировки: определение (BOM, UTF-8, UTF-16 без BOM, старые кодовые страницы), UTF-8 с BOM
      и без, UTF-16 LE/BE, старые кодовые страницы; «Encode in» (перечитать) и «Convert to»
      (перекодировать, с отменой); преобразования без потерь и надёжное сохранение на месте
      ([ADR 0007](adr/0007-encodings-and-saving.md))
- [x] Концы строк: определение и преобразование одним шагом отмены
- [x] Правка: режим замены, перемещение и удаление по словам, «умный» Home, настоящие позиции
      табуляции, вставка пробелов, горизонтальная прокрутка, двойной и тройной щелчок,
      мигающий курсор
- [x] Длинные строки: формируется только видимая часть ряда; перенос строк через карту
      отображения, готовую к свёртке; документы больше 4 МБ переносятся в фоне
      ([ADR 0008](adr/0008-editor-view-layout.md))
- [x] Простые поиск и замена (с учётом регистра, целые слова, по кругу, направление, Replace All
      одним шагом отмены), переход к строке или смещению, масштаб (запоминается), перенос строк
- [x] Строка состояния как у Notepad++, с меню конца строк и кодировки по щелчку
- [x] Единственный экземпляр с командной строкой, совместимой с Notepad++ (`-n`, `-c`, `-p`,
      `-ro`, `-multiInst`, `-nosession`; `-l` и другие параметры принимаются и пропускаются)
- [x] Первые устанавливаемые сборки: процесс выпуска с переносными ZIP (Windows x64/ARM64,
      Linux x64, macOS universal), MSI x64, SBOM и сведениями о происхождении; переносной
      режим; ручная проверка обновлений; About
      ([ADR 0009](adr/0009-releases-portable-mode-and-update-check.md)). Впервые выпущено как
      0.1.0; исполняемые файлы пока не подписаны.

То, что этап 1 оставил на потом, отмечено в следующих этапах как *(из этапа 1)*.

      ([ADR 0013](adr/0013-multi-editing-and-columns.md))
- [x] Умная подсветка выделенного слова в видимом тексте (настройки как в Notepad++, выключена
      сверх предела больших файлов); Style All Occurrences of Token и Style One Token с 5
      стилями, Clear Style, Jump Up/Down, Copy Styled Text; закладки (Ctrl+F2, F2, Shift+F2) и

      одним шагом отмены; назначения клавиш со сдвинутыми цифрами в Linux
      ([ADR 0014](adr/0014-smart-highlighting-token-styles-and-bookmarks.md))
- [x] Действия со строками: дублировать, удалить, переместить, вставить пустую, объединить,

      в предложении, инвертировать, случайно); построчные и блочные комментарии по знакам
      языка. Всё в `birchpad_core::ops`, каждое одним шагом отмены, с клавишами Notepad++
- [x] Сортировка по столбцам прямоугольного выделения
- [x] View > Show Symbol: пробелы и табуляции, концы строк (CR, LF, CRLF), Show All Characters,

      или фон за одним); текущая строка фоном или рамкой; Split Lines по границе или ширине

- [x] Разделённый вид: основной и второй виды рядом или друг над другом (Rotate Split View),

- [x] Сессии и периодическое резервное копирование несохранённых изменений, включая безымянные

      кодировки, сбой теряет не больше интервала копирования; настройки `session.*`, политика

- [x] Файлы, изменённые другими программами: отслеживаются через `notify` и проверяются при
      возврате в окно; перечитывание (молча или после вопроса) с сохранением курсоров, закладок
      и свёртки на своих строках; о несохранённых изменениях и удалённых файлах спрашивается;
      все, текущий или ни один файл (`files.change-detection`); View > Monitoring (tail -f)

- [x] Ночной канал с автоматическими обновлениями: ночные сборки `main`, если он изменился,
      манифест обновлений с подписью ed25519 и защитой от отката, заморозки и понижения версии,
      установщик Windows для пользователя (Velopack), обновляющийся сам, фоновые проверки
      (`notify`) и автоматические обновления (`auto`)
      ([ADR 0020](adr/0020-signed-updates-and-nightly-builds.md))
- [x] Длинные строки сохраняют раскладку при правке: индекс столбцов и ряды перенесённой строки
      обновляются вокруг правки; набор в строке на 10 МБ занимает 1,6 мс на нажатие (6,7 мс с
      переносом) вместо 49 мс (168 мс) ([ADR 0008](adr/0008-editor-view-layout.md))
      *(из этапа 1)*
- [x] Edit Anyway для файлов, которые не декодируются точно, после списка всех мест, где
      сохранение изменит байты файла ([ADR 0007](adr/0007-encodings-and-saving.md))
      *(из этапа 1)*
- [x] Строка меню с клавиатуры в Windows и Linux: Alt или F10, Alt+буква, мнемоники в меню,
      стрелки в подменю ([ADR 0019](adr/0019-menu-bar-keyboard-access.md)) *(из этапа 1)*
- [x] Столбцы считаются в ячейках терминала (широкие восточноазиатские символы занимают две)
      там, где Notepad++ считает символы: так и оставлено для прямоугольников, Column Editor и

- Проверить ввод через IME (Windows TSF, macOS, IBus/Fcitx) на настоящих системах; этап 1
  проверял ввод текста через обработчик ввода GPUI, но не с настоящим IME *(из этапа 1)*
- [x] Тесты того, что сохранение сохраняет ACL Windows, альтернативные потоки данных, время
      создания и ссылки *(из этапа 1)*

## Этап 6: полное соответствие Notepad++

То, что этапы 1–4 сделали иначе, чем Notepad++, или пропустили, здесь приводится в
соответствие; то, что этап 5 оставляет на потом, добавляется, когда сделано. Birchpad идёт
дальше Notepad++ только после этого этапа. Он выходит выпусками: сделанное к 2026-10-14 (6.1–6.21)
— как 0.2.0 вместе с issue, открытыми пользователями на GitHub ([Release 0.2.0](#release-020)),
исправления 0.2.5 ([Release 0.2.5](#release-025)), затем 0.3.0 (тесты), 0.4.0 (языки и текст),
0.5.0 (печать, инструменты и справка) и 0.6.0 (плагины, документация на русском, последнее
сравнение с Notepad++), который закрывает этап.

Каждый шаг следует правилам чистой комнаты из [CONTRIBUTING.ru.md](../CONTRIBUTING.ru.md#чистая-комната).
Шаги упорядочены по зависимостям; каждый выходит отдельным коммитом со своими тестами,
документацией и записью в `CHANGELOG.md`. Шаг, добавляющий возможность с настройками,
добавляет их и в Preferences; шаг 6.11 приносит разделы, которых не приносит ни одна
возможность.

### Разделение crate'а приложения

`birchpad` содержит больше половины кода рабочей области (около 48 000 из 83 000 строк): своё
окно и диалоги, но и логику, которой окно не нужно, и вид редактора, который пересобирает
каждое изменение панели или диалога. Эти шаги выносят и то и другое до того, как придут
оставшиеся возможности; поведение не меняется, тесты переезжают вместе с кодом.

- [x] 6.17 `birchpad-i18n`: локализация без окна (локали YAML и их разбор, именованные

      их английского
- [x] 6.18 Логика без окна, оставшаяся в `birchpad`, перенесена в crate'ы своего рода: чтение

## После 1.0.0

Пока не запланировано ни в один выпуск.

- [ ] Помощь ИИ, строго по желанию и никогда не навязываемая: выключена по умолчанию, и пока
      пользователь не включит её в Preferences, от неё ничего не видно (ни кнопки, ни пункта
      меню, ни предложения, ни совета, ни напоминания) и ничего никуда не отправляется; Birchpad
      никогда не предлагает её сам. Включённая, она работает только по просьбе пользователя
      (команда без сочетания клавиш по умолчанию), с выбранным пользователем поставщиком, в том
      числе локальной моделью, и показывает, что будет отправлено, до отправки. Политика
      `OnlineFeatures` убирает её полностью; сначала эти правила записывает ADR
