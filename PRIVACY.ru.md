# Политика конфиденциальности

[English](PRIVACY.md) · Русский

Birchpad не собирает персональных данных. В нём нет отчётов о сбоях и учётных записей, а ваши
документы, сессии и резервные копии остаются на вашем компьютере, в папке данных Birchpad (в
переносном режиме — в папке `data` рядом с ним). Проверки обновлений отправляют статистику
установок: она сообщает, какая копия Birchpad спрашивает, и ничего о вас; она описана
[ниже](#статистика-установок) и выключается одной настройкой.

## Сетевые запросы

Birchpad выходит в сеть только для обновлений и — когда вы просите — для установки PlantUML,
плагинов и словарей:

- **Проверка обновлений**: раз в день, пока Birchpad работает, и когда вы выбираете Help >
  Check for Updates, он запрашивает манифест обновлений у сервиса обновлений Birchpad:
  `POST https://api.birchpad.ru/v1/updates/check`, в теле запроса —
  [статистика установок](#статистика-установок), а при выключенной статистике — `{}`. Сервис
  отвечает манифестом в том виде, в каком он опубликован на GitHub, и Birchpad проверяет его
  встроенными в него ключами, как любой манифест. Если сервис не ответил или его ответ не прошёл
  проверку, Birchpad скачивает манифест с GitHub,
  `https://github.com/SecurityTrip/Birchpad/releases/download/updates/birchpad-updates.json`,
  туда ничего не отправляется. С настройкой `updates.url` (копия манифеста у администратора)
  Birchpad скачивает его только оттуда и статистику не отправляет. Каждый из этих запросов
  также сообщает, какая версия Birchpad спрашивает и в какой операционной системе (заголовок
  `User-Agent`, например `Birchpad/0.8.1 (windows)`), и ничего о ваших файлах.
- **Загрузка обновлений**: при `updates.mode = "auto"` (по умолчанию) копия, установленная
  установщиком Windows для пользователя, скачивает пакет новой версии с адреса, указанного в
  манифесте (загрузки выпусков GitHub).
- **Установка PlantUML**: когда вы нажимаете Install PlantUML в предпросмотре документа
  PlantUML (или View > Preview > Install PlantUML), Birchpad один раз скачивает PlantUML и Java,
  в которой он работает, из выпуска своего репозитория на GitHub (`plantuml-*`). При
  `network.online-features = false` — нет.
- **Онлайн-список плагинов и словарей**: когда вы нажимаете Refresh List в Plugins Admin или
  открываете Plugins > Spell Checker > Download Languages..., Birchpad читает список с
  `https://raw.githubusercontent.com/SecurityTrip/Birchpad/main/packaging/catalog/catalog.json`
  (или с адреса из `network.catalog`); когда вы устанавливаете из него плагин или скачиваете
  словарь, Birchpad скачивает их файлы по адресам из списка и сверяет с ним. При
  `network.online-features = false` — ни то, ни другое.

Эти запросы идут через прокси из Help > Set Updater Proxy... (`updates.proxy`), если он задан,
иначе через прокси из `HTTPS_PROXY` или `ALL_PROXY`, а в Windows — через системный.

Предпросмотр Markdown не загружает изображения из сети, а ссылка в нём открывается в браузере,
только когда вы на неё нажимаете. Диаграммы PlantUML рисует PlantUML на вашем компьютере (ваш
или установленный Birchpad), а не сервер. Языковые серверы (Настройки > Языковые серверы) — это
программы, которые вы настраиваете сами: Birchpad запускает их на вашем компьютере и передаёт им
текст ваших документов на их языке, а больше никуда ничего о них не отправляет. Git
(Настройки > Git) — это ваша собственная программа `git`, у которой Birchpad спрашивает
последний коммит ваших файлов и автора строки; она никогда не делает fetch, pull или push.

Остальные файлы раздаёт GitHub и, как любой веб-сервер, видит запросы: адрес вашего компьютера
или сети и время. На них распространяется его
[заявление о конфиденциальности](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

## Статистика установок

При `updates.statistics = true` (по умолчанию) проверка обновлений сообщает `api.birchpad.ru`:

| Поле | Что это | Зачем |
|---|---|---|
| `installId` | Случайный id (UUID версии 4) | Чтобы считать копии Birchpad, а не проверки |
| `version` | Версия Birchpad, например `0.8.1` | Чтобы знать, какие версии используются и когда старую можно перестать проверять |
| `channel` | `stable`, `beta` или `nightly` (`updates.channel`) | Чтобы знать, кто какие сборки получает |
| `platform` | `windows-x64`, `windows-arm64`, `linux-x64`, `macos-arm64` или `macos-x64` | Чтобы знать, какие сборки нужны |
| `plantuml` | Каким PlantUML рисуют предпросмотры: `component` (установленным Birchpad), `custom` (другим) или `none` (никаким) | Чтобы знать, доходят ли обновления PlantUML до тех, кто им пользуется |
| `plantumlVersion` | Версия PlantUML, установленного Birchpad, только при `component` | То же |

`installId` создаёт ваша копия Birchpad при первой проверке с включённой статистикой и хранит
в `state.toml` в папке данных Birchpad. Он случайный: он не выводится из вашего компьютера,
имени, учётной записи или чего-либо ещё и обозначает копию Birchpad, а не человека (у двух
пользователей одного компьютера или у переносной копии рядом с установленной — два разных id).
Больше ничего не отправляется: ни имён файлов, ни настроек, ни документов.

Сервис хранит одну строку на каждый `installId`: версию, с которой он появился впервые, и
текущую версию, канал, платформу, PlantUML и его версию, время первой и последней проверки. Он
не хранит IP-адреса, `User-Agent` и историю проверок.

Строки хранятся TODO(срок хранения). Чтобы удалить строку вашей копии, напишите на
TODO(адрес для удаления), указав её `installId` (`[updates] install-id` в `state.toml`).

При выключенной статистике тело запроса — `{}`: сервис тогда не узнаёт ничего сверх того, что
несёт скачивание манифеста с GitHub (адрес и `User-Agent`), и ничего не хранит. Выключение
статистики также удаляет `installId` из `state.toml`; если включить её снова, создаётся новый
id, ничем не связанный со старым.

## Как отключить

- `updates.statistics = false` (Preferences > Updates > Send install statistics) не отправляет
  статистику: проверки обновлений отправляют `{}`.
- `updates.mode = "off"` в настройках Birchpad прекращает запросы обновлений, а с ними и
  статистику.
- `updates.mode = "notify"` проверяет и сообщает о новых версиях, но ничего не скачивает.
- `network.online-features = false` прекращает установку PlantUML и чтение онлайн-списка
  плагинов и словарей; с обеими настройками Birchpad вообще не делает сетевых запросов.
- Администраторы могут задать то же политиками `UpdateStatistics` (0 выключает статистику),
  `UpdateMode` и `OnlineFeatures` (реестр Windows), которые пользователи изменить не могут; с
  `UpdateUrl` проверки обновлений идут к копии манифеста у администратора и статистику не
  отправляют.

Ссылка, которую вы решили открыть (Open Download Page в уведомлении об обновлении или домашняя
страница Birchpad, руководство и форум в меню Help), открывается в вашем браузере.
