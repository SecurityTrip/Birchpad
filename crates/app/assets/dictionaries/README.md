# Dictionaries bundled with Birchpad

`en_US.aff` and `en_US.dic` are the Hunspell dictionary of US English made from SCOWL by
Kevin Atkinson (wordlist.aspell.net), release 2020.12.07, as published in
`hunspell-en_US-2020.12.07.zip` (SHA-256
`616348ad645a716d91c8a6645065e710f15e9dda3ffef60cdf7ec8a4e27975af`), unchanged. Its license,
SCOWL's permissive license with the notices of the works it is made from, is in
`README_en_US.txt`, which is kept with the files as it requires.
